## About

This repository contains the source code for my personal developer portfolio. The website is designed as a central place to introduce my work, present selected projects, communicate my technical interests, and make it easy to get in touch.

The visual direction is modern and minimal, with a dark interface, cyan accents, layered surfaces, and subtle motion.

## Design Highlights

- **Dark editorial interface** — a deep navy background with clear typography and strong visual hierarchy.
- **Cyan accents** — focused highlights for links and calls to action.
- **Glass-inspired surfaces** — translucent, layered card treatments.
- **Motion and interaction** — subtle transitions and section-reveal animations.
- **Responsive presentation** — intended to provide a clear experience across screen sizes.

## Getting Started

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/) (version 16 or later)
- [pnpm](https://pnpm.io/) (version 7 or later)

### Installation

Clone the repository:

```bash
git clone https://github.com/Shah-Mohsin/shah-mohsin-portfolio.git
cd shah-mohsin-portfolio
```

Install dependencies:

```bash
pnpm install
```

### Development

Run the development command provided by the relevant workspace package. Check the package's `scripts` section for the available local development command.

### Build

Run the repository build script:

```bash
pnpm build
```

### Type Checking

```bash
pnpm typecheck
```
